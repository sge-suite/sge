# Sistema de Gestão de Estágios (SGE)

O **Sistema de Gestão de Estágios (SGE)** é uma aplicação web desenvolvida para gerenciar fluxos acadêmicos e administrativos relacionados aos estágios de discentes, envolvendo todos os interessados no processo de estágio.


## Tecnologias

Este projeto foi construído utilizando as seguintes tecnologias principais do ecossistema Laravel:
- **Laravel 13+**
- **PHP 8.5+**
- **Livewire 4+**
- **Flux UI**
- **Tailwind CSS**
- **Spatie Activitylog**
- **Spatie Medialibrary**
- **Spatie Permission**
- **Laravel Scout**
- **Meilisearch**
- **PostgreSQL**
